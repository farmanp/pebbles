# Security

Pebbles is an experimental single-user application that binds to loopback. It is not designed for public hosting or multi-tenant use. Keep source exports and decision handoffs on trusted storage. Back up the workspace database together with run evidence.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/farmanp/pebbles/security/advisories/new). Avoid filing public issues containing sensitive evidence or exploit credentials. Include affected commit, reproduction using synthetic data and likely impact.

No supported production release or response-time guarantee is currently offered. Authentication, authorization, secure shared hosting and tenant isolation are not implemented.
