# Results sheet guide

The workbook is facilitator-only. It contains planned trial IDs, phase, session, period, packet and condition. “Not run” is a planning status; all observed outcomes start blank. Schedule CSV is allocation, not results.

Use Submitted, Timeout or Technical failure after a task; never overwrite the original submission. Elapsed seconds is observed wall time, including loading and writing. Assistance count records facilitator interventions. Diagnosis, evidence and impact are integer 0–2; false assurance is 0 or 1. Leave unreviewed judgments blank. Submission reference points to the saved response. Notes include deviations, scorer identity, confidence if collected and false-assurance passages. Keep first scorer judgments and adjudication notes alongside the response.

Derived fields stay blank until the needed fields exist: total sums three scores; justified success requires Submitted plus 6/6 and no false assurance; time to justified answer is only defined for success; capped resolution is actual elapsed time for success and 900 seconds for submitted failures or timeouts. Technical failures have no derived success/time endpoint and must be reported separately. Do not encode unavailable values as zero. Pilot rows remain separately labeled and must be excluded from scored summaries.

Report all planned versus completed tasks, failures and exclusions with reasons. Use the protocol's descriptive analysis; the workbook deliberately does not produce a headline productivity claim.
