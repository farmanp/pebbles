Exact proposition/status/scope/assumption must appear together; no experiment badge/pass percentage. Separate execution. E02/E05 participants must name supported and unsupported facts unprompted; delivery/whole-experiment overreading is critical. Alternative: question-first report if status labels dominate qualifications.
2. **Blocker — Fixture lacks user journey.** Sources: target evaluation; BR-D01; fixtures/checker. Need scorecard, SQL where supplied, notes, provenance, omissions/conflicting narratives and independent rubrics. Definition/manifest/time not read by checker. Analyst-facing filenames must not reveal defects. Alternative: static comprehension test only until realistic investigation materials exist.
3. **Major — Submission cost can erase savings.** Sources: boundary §§1,5; target intent; technical core model. Allow unknown contextual fields, preserve originals/mappings, never infer semantics silently. Measure preparation, mapping corrections/help, analysis and follow-up. Manual mapping acceptable if measured; rigid schema versus guided mapping is a trade-off.
4. **Major — Discrepancy is not attributable defect.** Sources: E04, BR-D02/03, mutation, TC-05/06. Repeat exposure has distinct event ID. Orphan relative to partial export does not prove production fault. Separate observation, contract violation and candidate explanation; both-source provenance; no automatic raw-data authority. Clean repeated-user calculation must not fail.
5. **Major — Prioritize additional-evidence requests.** Sources: boundary §§2–5; target intent. Request smallest decision-relevant evidence, mark accessibility and permit unresolved limit. E03 asks for denominator/eligibility/attribution, not full infrastructure; E05 delivery unknown need not block analytical checks.
6. **Major — Memory and facilitation bias.** Sources: target evaluation; OP-1/CP-P. Matched forms change IDs/counts/defect locations; counterbalance; record baseline tools and assistance cost; blind scoring where feasible; preregister timing/quality/stops and report individuals. Small formative study preferred to overclaiming efficacy.

## Proposal and alternatives

Proposed readiness review, two 45-minute comprehension pilots, then four–six additional analysts up to 90 minutes with balanced subset tasks; two-week/40 staff-hour cap excluding recruitment. Targets proposed: all critical technical checks, zero false assurance, at least 80% scope-answer accuracy with any delivery assurance error forcing revision, no worse consequential detection/justification, 20% lower total effort. Three analysts describing analogous recent work supports discovery only. Open choices: E01 defect, E02 aggregate checks, SQL inspect/execute, timing unit, participants, report usability versus automated performance. Concierge can test usefulness, not automated accuracy or savings.
